# 지형도면고시도 생성기

필지 지번 목록(xlsx·csv)만으로 「토지이용규제 기본법」 시행령 제7조와
「지역·지구등의 지형도면 작성에 관한 지침」 규격에 맞는 **지형도면고시도 PDF**를
자동으로 만드는 윈도우 프로그램입니다.

## 내려받기

[Releases](../../releases/tag/app) 에서 `지형도면생성기.exe` 를 받으세요.
설치가 필요 없고, 프로그램 안에서 새 버전을 자동으로 확인·교체합니다.

처음 실행할 때 V-World 오픈API 인증키를 한 번 넣어야 합니다
(무료 발급: <https://www.vworld.kr> → 오픈API → 인증키 발급).

## 등고선

등고선은 세 가지 방법으로 넣을 수 있습니다.

| 방법 | 자료 준비 | 정밀도 |
|---|---|---|
| **자동 다운로드** | 필요 없음 (도면 범위에 걸리는 10km 블록만 내려받음, 보통 2~8MB) | 국토지리정보원 원본 5m |
| 로컬 SHP 폴더 | 연속수치지형도 등고선을 미리 내려받아 둠 | 국토지리정보원 원본 5m |
| 웹 표고타일 | 필요 없음 | 약 30m 급 (참고용) |

자동 다운로드용 블록 팩은 [contour 태그](../../releases/tag/contour) 에 있습니다.

## 자료 출처

- 연속지적도·용도지역·행정경계: 국토교통부 **V-World** 공간정보 오픈플랫폼
- 등고선: **국토지리정보원** 연속수치지형도 (공공누리 제1유형, 출처표시)
- 웹 표고타일: AWS Terrain Tiles (SRTM 계열)

등고선 블록 팩은 국토지리정보원 원본을 이 프로그램이 읽는 형식으로 변환한
2차적 저작물이며, 원저작물의 출처는 국토지리정보원입니다.
